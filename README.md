# Bunny Twin Quiz!
A simple personality kinda quiz to find out your bunny twin!

-This is a simple quiz test that assigns you a bunny based on your answers!

#Made Using:

- HTML
- Css
- JavaScript
- Made at Github Codespaces
- Art drawn by me using Pixil


#How it was built:

This is a beginners project I made to get better at building websites and learning html/css/js. First the html structure was made then stylzed with css before adding all the functions and buttons with javascript. I also hand drew all the pixel illustrations using pixil on web and implmeneted them to the code. Pushed it to Github Pages and was all done! 


#How to use it:

Take the test here: https://hime2bahan.github.io/what-kinda-bunny-resembles-you-/


#AI Usage

I used AI for troubleshooting purposes as well as instructions to add features (such as some of the animations) that was my first time trying in my projects.
